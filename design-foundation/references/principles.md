# 判断の根拠となる原則

design の各スキルが、判断の理由として参照する原則の一覧。理由には見出しの原則名（例：`principles#thumb-zone`）を書く。
数値は目安であり、ペルソナと利用状況で調整する。調整した場合は、その理由を `UI-N` に書く。

## 認知と判断

### hick
選択肢が増えるほど、選ぶ時間が長くなる（ヒックの法則）。
- 1画面の主要な操作は1つに絞る。二次的な操作は視覚的な強さを下げる。
- 選択肢が多い場合は、分類、検索、既定値の提示で減らす。

### chunking
人が一度に扱える情報のかたまりは少ない。
- 長い入力やリストは、意味のまとまりで区切る（例：電話番号の区切り、フォームの段階分け）。

### progressive-disclosure
最初は必要な情報だけを見せ、詳細は求められたときに出す。
- 情報の優先度を P1（常に表示）、P2（1操作で表示）、P3（別画面）、非表示に分ける。

### recognition
覚えさせるより、見て選ばせる。
- 直前の入力、履歴、候補を表示する。アイコンだけで意味を伝えない（ラベルを併記する）。

### jakob
利用者は他の製品で慣れた操作を期待する（ヤコブの法則）。
- 独自の操作方式は、慣習に従うより明確に有利な場合に限る。その理由を `UI-N` に書く。

## 視覚

### hierarchy
大きさ、太さ、色の強さ、余白、位置で重要度を示す。強さの段階は3〜4段に抑える。

### gestalt
近いもの、似たもの、同じ枠に入ったものは、まとまりとして見える。
- 関係する要素の余白は、関係しない要素の余白より小さくする。

### scan-pattern
文字の多い画面はF型、要素の少ない画面はZ型に視線が動きやすい。
- 最初に見せたい情報を、視線の始点（左上。右から左に読む言語では右上）に置く。

### color-meaning
色だけで意味を伝えない（WCAG 2.2 1.4.1）。
- エラーや状態は、色に加えてアイコンか文言で示す。
- 色は役割で定義する（primary、danger など）。値で直接指定しない。

## 操作

### fitts
目標が大きく近いほど、速く正確に押せる（フィッツの法則）。
- 頻繁に押すものと重要なものは、大きく、手や視線の近くに置く。
- 取り消せない操作は、主要な操作から離す。

### thumb-zone
片手でスマートフォンを持つと、画面の下半分の中央が最も押しやすく、上端の角は届きにくい。
- 片手で使うペルソナでは、主要な操作を画面の下部に置く。
- 届きにくい位置には、頻度の低い操作を置く。

### target-size
押せる領域の最小値の目安。

| 基準 | 最小の大きさ |
|---|---|
| WCAG 2.2 2.5.8（AA） | 24×24 CSS px（または十分な間隔） |
| WCAG 2.2 2.5.5（AAA） | 44×44 CSS px |
| Apple HIG | 44×44 pt |
| Material Design | 48×48 dp |

### feedback
すべての操作に反応を返す。
- 押した直後（100ms 以内の目安）に見た目を変える。
- 1秒を超える処理は進行を示す。完了と失敗を明示する。

### error-prevention
失敗を起こしにくくし、起きたら戻れるようにする。
- 入力の形式を制約する（入力モード、選択式）。エラーは入力欄の近くに、直し方と一緒に示す。
- 削除などは、確認より取り消し（Undo）を優先する。

## 動き

### motion-purpose
動きには目的を1つ持たせる。目的のない動きは使わない。

| 目的 | 例 |
|---|---|
| フィードバック | 押下、保存の完了 |
| 状態の連続性 | 一覧から詳細への遷移で、要素がつながって見える |
| 注意の誘導 | 新しく追加された項目を一度だけ示す |
| 空間の理解 | シートが下から出て、下に戻る |

### motion-duration
時間の目安。画面が大きく、移動距離が長いほど長くする。

| 種類 | 目安 |
|---|---|
| 押下、ホバー、切り替え | 100〜150ms |
| 部品の開閉、出現 | 150〜250ms |
| 画面の遷移 | 250〜400ms |

- 出現は減速（ease-out）、退出は加速（ease-in）、移動は ease-in-out を基本にする。

### reduced-motion
`prefers-reduced-motion: reduce` のとき、移動、拡大縮小、視差を止める。フェードと色の変化は残してよい。

## アクセシビリティ

### contrast
WCAG 2.2 のコントラスト比。

| 対象 | AA | AAA |
|---|---|---|
| 本文（通常の文字） | 4.5:1 | 7:1 |
| 大きな文字（18pt 以上、または 14pt 以上の太字） | 3:1 | 4.5:1 |
| UI 部品の境界、アイコン、フォーカスの表示（1.4.11） | 3:1 | ― |

### keyboard
すべての操作をキーボードで行える。フォーカスの位置が常に見え、順序が視覚の順序と一致する。
