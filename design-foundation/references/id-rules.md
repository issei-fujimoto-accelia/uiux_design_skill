# ID の規則（design 用）

design の文書で ID を定義・参照するときの規則。所有と由来の一覧は [CONTRACT.md](CONTRACT.md) の3章にある。
base を併用するプロジェクトでは、base の ID 規則も同時に満たす（内容は同じ）。

## 定義

その ID の所有文書で、表の行の先頭セル、見出し、または箇条書きの先頭に ID を置く。

- 表：`| SCR-3 | 申込み確認 | … | FR-12 |`
- 見出し：`### PSN-1：通勤中に片手で使う会社員`
- 箇条書き：`- UI-7：…`

## 参照

- 定義以外の場所に ID を書く。
- 範囲表記（`SCR-1〜4`）を使わない。`SCR-1, SCR-2, SCR-3, SCR-4` と列挙する。

## 由来

- 定義と同じ行に、上流の ID を書く。見出しで定義した場合は、見出しの直後の行に書く。
- 上流の文書に ID がない場合は `外部:<パス>#<見出し>` と書く。
- どこにも由来しない場合は `追加：<理由>` と書く。

## 理由

`UI-N` と `SCR-N` と `CMP-N` には「理由」列を設け、なぜそう決めたかを1文で書く。
理由には、根拠となる `PSN-N`、利用状況、または `references/principles.md` の原則名を含める。

## 変更

- ID を振り直さない。番号は欠番になってよい。
- 削除するときは行を消さず、`（廃止）` と書いて残す。廃止した ID は再利用しない。
- 内容を大きく変えるときは、元の ID を廃止して新しい ID を振る。
